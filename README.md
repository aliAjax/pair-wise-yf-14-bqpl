# hxyfront-62002 剧场灯光Cue表管理

给剧场灯光师使用的灯位与 Cue 表管理前端，适合排练期间快速调整。

## 功能

- **三层数据分开维护**（localStorage 持久化）
  - 灯具层：编号、类型、通道号、色片、焦点位置、**焦点确认**
  - Cue 依赖层：Cue 顺序、关联灯具、亮度预设（跨版本共享）
  - 版本进度层：每条 Cue 的触发状态、触发时间、排练备注（按版本独立）
- **演出版排练进程**
  - 灯具焦点确认后，关联 Cue 才进入「待触发」
  - 通道号撞车（同通道多盏灯）的 Cue 锁定，改通道号后自动解锁
  - 前一条 Cue 未触发完成，后一条不能触发；撤销前序后标记「链条中断」
  - Cue 状态三档：未就绪（灰）/ 待触发（橙）/ 已触发（绿），阻塞原因逐条列出
- **切版本不丢进度**：内置「旧版 · 录资料」（保留原有进度与备注）与「演出版 · 联排」，可新建版本，互不影响
- 舞台平面灯位图（焦点光束线 + 状态描边）与 Cue 列表都实时显示当前状态
- 当前场景预览随最后触发的 Cue 变化；支持按灯具类型筛选
- 规则引擎测试：`node scripts/test-rules.mjs`（13 项）

## 技术栈

React 19 + Vite + TypeScript（无额外 UI 依赖）

## 本地运行

```bash
npm install
npm run dev
```
